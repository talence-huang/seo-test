開始一次研究

Agent 只抓公開頁面、遵守 robots.txt 與每個網站 2 秒的抓取間隔，並用 Wayback Machine 比對頁面歷史版本。沒有排名歷史，所以研究的是「競品在這些關鍵字做了什麼內容策略」。開始前會請求一次首頁以確認正式網域。

LLM

真實網站建議使用真實 Opus：假 LLM 只是測試用的規則式替身，只會從排名網址或已確認的變動範本提出假設，常常得不出結論。
