SEO 競爭情報研究 Agent

研究競品網站

從 Ahrefs（Backlinks）或 Semrush（Backlinks）匯出競品與自家網站的反向連結；至少需要「來源網址、目標網址」，建議包含錨點文字與首次發現日期。依目標網址自動分到各網站。

研究要回答三個問題：競品的 On-page 策略、Off-page 策略，以及我們最值得優先採取的行動。Agent 只抓公開頁面、遵守 robots.txt 與每個網站 2 秒的抓取間隔，並用 Wayback Machine 比對頁面歷史版本；開始前會請求一次首頁以確認正式網域。

進階：預算

預算用盡但還有驗證工作時，Agent 會停下來請你核准延長。每次抓取間隔約 2 秒，80 次約 3 分鐘。
